# 工作台 v2 · 改版规划

> 目标：把「待办清单」换成「会进化的备忘录」，让记录、日程、周报共用同一份数据。
> 形态：DSH 右侧栏常驻 tab，300–480px 单列。视觉走 Material Design（附件风格）。
> 状态：已实现（v2.1.0）｜2026-11-17

## 1. 这次为什么改

| 旧版 | 问题 | v2 |
|---|---|---|
| 待办五态（待办/进行中/阻塞/完成/取消） | 每记一件事先要求你选状态，像在维护一个项目管理系统 | 一条备忘只有「未勾选 / 已勾选」，勾选后划线，不强迫分类 |
| 一条条独立任务 | 不符合「先记下来，之后再想」的工作习惯 | 记事本式连续记录：一段话、一个灵感、一句会议结论都能存 |
| 信息跟踪（关键词扫描/时间轴/可信度） | 维护成本高，且与日常记录割裂 | **整块删除**（含 Host 扫描路由、关键词和定级逻辑） |
| 统计 | 只有数字，周五仍要考古写周报 | 周报 tab：本周数据 + AI 总结，直接可复制 |

核心判断：**记录的门槛要低到接近便签，整理的价值放在「回看」和「AI 总结」上，而不是录入时。**

## 2. 三个 tab

```
┌────────────────────────────────────┐
│  工作台            11月17日 · 周一  │  ← 紫色 Hero + 本周进度环
│  ────────────────────────────────  │
│   备忘      日历      周报          │  ← Material tabs
│  筛选  全部 未完成 重要 今天        │
│  今天 · 2                          │
│  ☑ 写完了，划线                    │

│  │ 记点什么… 明天 15:00 对齐 #重要│  │  ← 底部常驻输入框
│  │ [明天 15:00] [重要]      [→]  │  │
│  └──────────────────────────────┘  │
└────────────────────────────────────┘
```

### 2.1 备忘

- 记事本式卡片，不做「任务行」。一条可以是一句话、一段多行文字、一个灵感。
- 勾选框：勾选后整条文字划线并降透明度，进入「已完成」分组；再点恢复。
- 标签：`#重要` `#不重要` `#紧急` `#想法` `#会议` `#客户`，可自由输入任意 `#标签`；输入框下方有快捷 chip。
- **标签可管理**：标签行「管理标签」支持新增/重命名/删除；重命名同步所有备忘，删除从所有备忘移除；备忘编辑态也能直接加新标签。
- 截止日期：任意日期 + 可选时间；卡片上以 chip 显示（今天/明天/逾期 N 天/10月30日）。编辑态可直接改。
- 其他：置顶、删除（5 秒撤销）、编辑、按「全部 / 未完成 / 重要 / 今天」筛选。
- **一键对话**：点击备忘卡片，右侧滑出操作抽屉；「对话」会把正文、标签、截止日期、状态、id 作为上下文追加进当前 DSH 对话并发送，「更多」里是置顶/编辑/删除。agent 可以直接开始处理，并在需要时用 `pm_memo_update` 回写状态。
- 分组顺序：置顶 → 已逾期 → 今天 → 本周 → 以后 → 无日期 → 已完成（默认折叠）。

**录入语法**（本地即时解析，不等 AI）：

```text
明天下午 3 点跟设计对齐会员改版 #重要
周五前补验收标准 #会员 #紧急
下周一 10:00 周会
记一下：空状态文案再想一版
```

解析出 `明天 + 15:00 + 重要`，标题保留「跟设计对齐会员改版」。输入框实时显示识别结果，错误可以直接改日期/标签，不打断输入。

**长文本批量录入**：多行或超过 50 字时，Enter 变成「AI 识别」——把整段会议纪要/聊天记录/长想法按语义拆成多条备忘（带日期/时间的写进截止日期），逐条勾选后一次保存（最多 12 条）；`Ctrl/Cmd+Enter` 始终存为一条，拆分预览里也有「存为一条」。AI 失败时退回本地按行/句拆分，并标注「本地识别」。

### 2.2 日历

- 月视图（周一开始）+ 选中日议程。窄栏下不做好几列周视图。
- **只读投影**：备忘的截止日期/时间自动出现在日历上；日历里不单独添加日程，避免出现两套数据。
- 有时间的条目排在议程的时间轴上；无时间的作为「全天」。
- 点条目会跳回备忘 tab 并高亮那一条；议程里可以直接勾完成（操作的仍是备忘）。
- AI 识别统一放在**备忘 tab**：输入框下方的「AI 识别」或长文本 Enter 打开同一个拆分预览，所有结果都写成带截止日期的备忘；日历只是它们的视图。
- AI 失败时保留本地规则解析的结果，并在结果上方明确标注「AI 不可用，已用本地规则解析」。

### 2.3 周报

- 本周数据：完成 / 新增 / 进行中 / 重要，四个数字卡。
- **AI 总结本周工作内容**：调用当前默认模型，输出结构化周报：
  - 一句话标题
  - 2–4 句概述
  - 完成 / 推进 / 风险 / 下周计划 四组要点
- 结果按「周」缓存，重新生成会覆盖；支持复制 Markdown。
- AI 不可用时（未配置模型/超时/网络失败）自动降级为**本地汇总**，数据仍然完整，并明确标注「本地生成」。
- 周切换：看上一周/下一周，方便补周报。

## 3. AI 设计

### 3.1 调用位置

所有模型调用都在 **Host** 侧完成：客户端只 POST `/pm-workbench/ai`，浏览器不接触密钥。模型路由取 `agentDefaultModel.currentSelection()`（当前默认模型）；取不到时回退到活跃会话的 provider/model，再回退到任一可用模型。

### 3.2 两个任务

| task | 输入 | 输出 |
|---|---|---|
| `parse` | 一段自然语言（≤6000 字）+ 当前时间 | `{ memos: [{text,tags,dueDate,dueTime}] }`（最多 12 条；日期/时间写进 dueDate/dueTime） |
| `summary` | 本周备忘与日程（精简字段） | `{ headline, summary, done[], progress[], risks[], next[] }` |

约定：只输出 JSON；Host 会剥掉```代码围栏并做字段清洗；客户端再做一次白名单校验。模型超时 45s、输出上限 1600 tokens，并请求模型支持的最低 reasoning 档位，避免把预算花在思考上。

### 3.3 降级

- `parse` 失败 → 本地规则解析（按行/分号/句号拆条，识别日期时间与标签）。
- `summary` 失败 → 本地统计生成同样的四组结构。
- 两种降级都在 UI 上标注来源（`AI` / `本地`），不假装是 AI 结果。

### 3.4 微信 / IM：共享数据与 Host 工具

原版数据只在浏览器 localStorage，agent 读不到。v2.1 把 **Host 文件**作为共享数据源：

- 路径：`$DSH_HOME/storages/pm-workbench/workbench.json`；浏览器 localStorage 降为缓存。
- 客户端启动时与 Host 合并；之后本机编辑 POST 到 Host，Host 工具改动每 5 秒轮询回 UI。
- Host 注册 5 个普通 DSH 工具：`pm_memo_list`、`pm_memo_add`、`pm_memo_update`、`pm_memo_delete`、`pm_workbench_stats`。微信机器人（dsh-im）走普通 agent 会话，因此自然语言可直接调用这些工具。
- 删除要求 `confirm:true`；更新支持 id 或唯一正文片段。
- 升级后需要打开一次工作台，旧 localStorage 才会迁入 Host；之后微信才能读到同一份数据。

## 4. 视觉规范（Material Design）

取附件风格指南的骨架，按右侧栏宽度重排：

| 项 | 取值 |
|---|---|
| 主色 | `#6200EE`（Primary）/ `#3700B3`（深）/ `#7C4DFF`、`#B388FF`（浅） |
| 辅助色 | `#03DAC6`（Teal，用于进度/成功点缀） |
| 表面 | 全部取宿主主题 token（`--dsw-alias-bg-layer-1/2`、`label-primary/secondary`、`border-l1/l2`），深浅色主题自动跟随（深色由 `body[data-ds-dark-theme]` 切换紫色档位） |
| 字体 | Roboto 优先，中文回落 PingFang SC / Microsoft YaHei；标题 15–17，正文 12–13，辅助 10–11 |
| 圆角 | 卡片 16，输入框 14，按钮 999 或 14，Chip 999 |
| 阴影 | 1px 边框 + 两层柔和阴影（`0 1px 2px` + `0 8px 24px rgba(98,0,238,.08)`） |
| 动效 | 150–220ms；勾选缩放、卡片 hover 上浮 1px、tab 指示条、AI 骨架 shimmer |
| 图标 | 16px 线性图标，`currentColor`；输入框固定在面板底部 |

组件对齐附件中的 Button / Chip / Checkbox / Calendar / Card 语义，但不搬大屏布局；不使用右下角 FAB，主操作统一放在底部输入框或所在页工具栏。

## 5. 数据与迁移

- 新存储键 `dsh.pm-workbench.v2`：`{ v:2, memos, events, reports, ui }`。
- Host 共享文件 `$DSH_HOME/storages/pm-workbench/workbench.json`，客户端 localStorage 作为缓存并在启动时与 Host 合并；导出 JSON 可备份，导入可恢复。
- 首次加载检测旧键 `dsh.pm-workbench.v1`：把旧 `todos` 转成备忘（标题、标签、截止日、完成态），**丢弃 keywords/intel**。
- `reports` 按 `YYYY-MM-DD`（周一）缓存，避免重复调用模型。

## 6. 明确不做

- 不做项目/看板/多级任务、不做重复任务、不做提醒推送。
- 不做跨设备同步（Host 文件只服务本机 DSH；跨设备不在本期）。
- 不做信息跟踪的任何残留入口。
- 不做大屏日历（右侧栏只有单列）。

## 7. 验收口径

1. 旧待办数据首次打开可见，信息跟踪入口完全消失。
2. 输入一句话（含日期/标签）回车即存；勾选划线；日期可改；删除可撤销。
3. 日历能看到备忘截止日；AI 识别能把一段话拆成带日期的备忘并写入。
4. 周报能生成结构化总结；断网/无模型时降级为本地汇总且不报错。
5. 300px 下不横向滚动、不出现三行截断；深浅色主题文字可读。
